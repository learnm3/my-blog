# 项目需求文档

## 项目概述

个人博客/作品集网站，面向招聘者展示项目经历和技术能力。

## 目标用户

- 技术招聘者（HR、技术负责人）
- 潜在的技术合作者

## 功能需求

### F1 - 首页

- 个人名称展示（NoFinalLevel）
- 一句简短的个人介绍/定位
- 导航链接到项目页和展廊页
- 给招聘者留下良好的第一印象

### F2 - GitHub 项目展示

- 自动从 GitHub API 拉取用户 `learnm3` 的公开仓库
- 展示每个仓库的名称、描述、编程语言、Star 数、更新日期
- 以卡片网格形式呈现
- 按 Star 数降序排列
- 加载时显示骨架屏

### F3 - 图片展廊

- 以网格形式展示图片
- 点击图片可放大查看（灯箱模式）
- 支持键盘导航（← → 切换图片，Esc 关闭）
- 初始使用占位图片数据

### F4 - 桌面宠物

- 像素风格小猫，全局显示在页面右下角
- 纯 CSS 动画（上下浮动 + 来回走动）
- 不遮挡页面内容（pointer-events: none）
- 亮色/暗色模式下均可见

### F5 - 主题切换

- 支持亮色模式和暗色模式
- 手动切换按钮，位置在导航栏
- 暗色模式自动适配所有页面
- 主题偏好持久化（localStorage）

## 非功能需求

- 响应式设计，适配手机、平板、桌面
- 页面加载性能良好
- 代码结构清晰，便于后续扩展

## 暂不包含（后续迭代）

- 小游戏
- 关于我/简历页
- 博客文章
